Combine conditions without inventing certainty

Intersection (all), union (any) and complement (not) evaluate the same indexed symbol population. Missing effect, tag or test evidence stays unknown—even under not. These are explicit static filters, not arbitrary natural-language business conclusions.

Available predicates

name, kind, language, effect and tag take a value string. hasTest has no value and means resolved static test reachability, not executed assertion coverage. changed takes beforeRevisionId and compares file text. Boolean groups use {op:all/any,args:[...]}; complement uses {op:not,arg:{...}}. At most 32 predicates and 8 levels.

Compose read-only questions

Run up to six explicit questions in sequence. Completed answers are saved independently; failed steps do not discard them. Plans run against the selected current snapshot. This does not execute repository code.

Dependent steps

JSON steps support question, intent, symbolId and fromStep (zero-based earlier index). A dependent target is used only when that step has exactly one unchallenged symbol; ambiguous results fail explicitly.

Recorded evidence and investigations

Import a trace, profile or test report

Report schema and mapping rules

Provide repositoryId, revisionId, environment, producer, kind (trace, profile or tests), and events. Each event needs id, name, startMicros, endMicros and outcome (ok/error/unknown/passed/failed/skipped). Optional parentId must refer to another record in this report. Profile records require samples. To map to code, provide file, line and sourceHash together, matching the exact indexed source; otherwise omit them and the record remains unmapped.

Times are nonnegative integer microseconds on the producer's reported time axis. Events from different clocks need normalization by the producer. No missing event is inferred.

Evidence notation and keyboard help
