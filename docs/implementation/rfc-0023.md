# RFC-0023 implementation

The amended stages in §11 are implemented on top of RFC-0024's coordinated
contract/runtime/planner commits through e049fc1. Stage 0 was already present.

## Stage 1 — verify and complete the G6 host

Preserve adapted graph data on the non-tree canvas path. Use the shared
selection hub and bound conflicting reentrant callbacks to one deferred pass;
listeners receive isolated snapshots. Render failures destroy the canvas.
Disclose the adapter's actual negotiated layout, including substitution.

Validation: 306 adapter tests pass; adapter and web TypeScript checks pass.
`node --test web/test/rfc0023.test.cjs` exercises the host with a mocked G6
boundary, verifying that data reaches the graph and programmatic echoes stop.
Live canvas integration is validated in the final stage.

## Stage 2 — sealed sheet planning

Added the engine-level pure `planSheet` API alongside the persona presentation
planner. Chart presence follows actual containment/relations, scoped element
sets and Facts-only preferences; engine selection uses the negotiator's canvas
and interaction capabilities. Narrow viewports reduce chart count, not facts.
Three tests cover deterministic plans, filtering, viewport and gate rejection.
Adapter suite: 309 passing tests; TypeScript passes.
