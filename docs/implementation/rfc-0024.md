# RFC-0024 implementation record

The per-stage validation record (pattern of `docs/implementation/rfc-0022.md`).
RFC-0024 §4 is the stage plan; each section below records what landed, the
verification actually run, and anything the stage deliberately did NOT do.

## Stage 0 — the three contract patches + catalog kinds + gate checks

**Landed (commit range recorded in git history):**

1. **Patch 1 — `RenderHandle.onSelection` / `setSelected`** (`viz-adapter/src/types.ts`):
   the render-handle surface gains `onSelection(cb): () => void` and
   `setSelected(ids, origin)` with the new `SelectionOrigin`
   ('user' | 'programmatic') and `SelectionListener` types. The loop-guarded
   semantics are implemented EXACTLY once in `viz-adapter/src/selection.ts`
   (`createSelectionHub`, headless-pure): identical sets never re-fire
   (echo suppression, counted), re-entrant calls from inside a listener are
   coalesced into one deferred pass (depth cap 1, dropped calls counted) —
   an engine click-echo cannot loop by construction.

2. **Patch 2 — `HiddenCandidate.label` + `.kind`** (`types.ts`) and the G1
   disclosure rows (`disclosure.ts` `hiddenRows()`): rows fall back to
   `id`/`unknown` when the producer recorded no patch-2 fields and DISCLOSE
   the fallback (`fallback: true`) — never a blank row, never a re-order.

3. **Patch 3 — `fields.bodyLines[]` gate rule + `fields.alsoEvidence[]`**
   (`types.ts` `BodyLine`, `gate.ts` `gateFields()` wired INTO `gate()` so
   there is no bypass; `errors.ts` codes `BODY_LINE_WITHOUT_EVIDENCE`,
   `ALSO_EVIDENCE_MALFORMED`). Rule: every body line carries its own
   well-formed EvidenceRef (non-empty file, end ≥ start ≥ 0); every
   alsoEvidence ref is well-formed (paired popups never draw a blank
   column). Elements without these fields are untouched — additive only.

4. **Catalog** (`catalog.ts`): `C10 Component board` registered (Custom —
   the g6 node-kind budget is spent exactly on RFC-0024's four kinds:
   process/decision/store/board-card), plus the per-kind drill/filter
   action matrix (`ChartAction`, `CATEGORY_DEFAULT_ACTIONS`, `actionsFor()`)
   per ux-spec §3/§8: structural/architectural boxes drill, code-level and
   statistical cells filter (a line is a fact, not a scope); the board
   card never scopes.

5. **Rust gate mirror** (`cie-viz/src/gate.rs`): `GateCode::
   BodyLineWithoutEvidence` / `AlsoEvidenceMalformed` with the identical
   stable strings, the identical well-formedness rule (`well_formed_ref`),
   both checks run inside `validate()` (no producer bypass), + 6 Rust tests.
