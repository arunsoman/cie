# RFC-0022 implementation follow-through

This record describes the follow-through on the implementation already present
at `bba0ccc`. RFC-0022 §13 is the historical audit of that earlier implementation.

## Stage A: revision-safe navigation and embeddings

- Unchanged org ingests now materialize snapshots. Unresolved calls are persisted
  per revision, so cross-repo candidate links survive reloads.
- Missing legacy navigation artifacts rebuild from source only after checking
  revision and content hashes. Existing artifacts are read without reparsing.
- Graph nodes and unresolved callers are remapped to the final snapshot ID space
  after tombstone compaction. File tables are persisted too: cached citations
  retain their paths and lines. Legacy source offsets are recovered only from
  byte-identical source; unavailable offsets remain unknown.
- Trace supports `--kind all`, rejects ambiguous symbols, and reports unseen
  nodes beyond its depth boundary accurately, including depth zero and cycles.
  Help names the four populated production relation kinds. The other six kinds
  remain unpopulated; this work does not invent statement facts or PDG evidence.
- Search exposes explicit provider, offline override, estimated spend cap and
  KNN time budget. The default remains offline. Analysis labeling remains
  offline in a search invocation; provider opt-in applies to embeddings only.
- Embedding artifacts identify their model/endpoint space (endpoint identity is
  hashed, credentials excluded). Provider switches re-embed the entire corpus,
  even at equal dimensions. Legacy unidentified spaces are rebuilt.
- Changed text alone is embedded; deleted records disappear. Invalid response
  cardinality/dimensions/nonfinite values or provider/query failures trigger
  a complete offline corpus/query pairing, never a mixed-space index. External
  spend estimates are charged before requests. The estimate is not a provider
  billing guarantee. JSON states the actual provider and fallback reason.
- No-op search does not rewrite unchanged embeddings. A missing embedding
  artifact is repaired without changing the revision.

## Scope boundaries

MCP tools remain blocked on RFC-0021's real executor. No stub tools are advertised.
Cross-repo matching still uses globally unique short names, not workspace/import
resolution or exported-visibility proof; these are candidate associations and
must not be represented as verified runtime or API calls. The HNSW graph is
rebuilt from persisted vectors for each search; this is not a durable native
HNSW graph or a sharded index. KNN's time budget excludes ingestion, index rebuild
and provider request latency (providers retain their existing network timeouts).
